It’s vexing to wait for your game to load. Minecraft could be pretty tough on some computers to run. So in order to make Minecraft run faster and reduce lag, you can read this post and follow the tips to boost the game performance.

## Method 1: Change Game Settings

 The easiest and quickest way to speed up Minecraft is to lower or turn off the game settings. Below are the settings you can turn off and lower to make the game run faster.

1. [**Choose default package**](https://tools.techidaily.com/drivereasy/download/)
2. [**Lower the Video Settings**](https://tools.techidaily.com/drivereasy/download/)
3. [**Change the Minecraft game resolution**](https://tools.techidaily.com/drivereasy/download/)
4. [**Turn off Sound in Minecraft**](https://tools.techidaily.com/drivereasy/download/)

### 1\. Choose the default package

 The resource packages have loaded into RAM which will lower the speed of the game. So we recommend using the default package which can meet your basic need.

1. Click**Options** .  
![](https://images.drivereasy.com/wp-content/uploads/2019/09/mine7.jpg)
2. Click**Resource Packs** .  
![](https://images.drivereasy.com/wp-content/uploads/2019/09/mine9.jpg)
3. Click**Default** then click**DONE** .  
![](https://images.drivereasy.com/wp-content/uploads/2019/09/mine6.jpg)
4. Play the game to check.

### 2\. Lower the Video Settings

 Fancy video settings can bring you nice pictures but they can also make your computer work with more stuff that lowers the gaming speed. So setting your game in low settings can make Minecraft run faster.

1. Click**Options** .  
![](https://images.drivereasy.com/wp-content/uploads/2019/09/mine7.jpg)
2. Click**Video Settings.**  
![](https://images.drivereasy.com/wp-content/uploads/2019/09/mine8.jpg)
3. Set Graphics as Fast.

4. Turn Smooth Lighting off.
5. Turn 3D Anaglyph off.
6. Turn Use VSync off.
7. Turn View Bobbing off.
8. Turn Clouds off.
9. Lower Max Framerate.  
![](https://images.drivereasy.com/wp-content/uploads/2019/09/mine10.jpg)
10. Play the game to check.

### 3.**Change the Minecraft game resolution**

 Lowering the resolution will make the game window smaller, but can help increase your performance.

1. Run Minecraft, and click the menu button in the right-topper corner.  
![](https://images.drivereasy.com/wp-content/uploads/2019/09/mine1-1.jpg)
2. Click**Launch options** \>**Advanced settings** \>**Add new** .  
![](https://images.drivereasy.com/wp-content/uploads/2019/09/mine2-1.jpg)
3. Add a name then click**Resolution** .  
![](https://images.drivereasy.com/wp-content/uploads/2019/09/mine11.jpg)
4. You can change the size as you like, then click**Save** .
5. Back to the**News** tab, click the arrow button beside**PLAY** and choose the name you add.  
![](https://images.drivereasy.com/wp-content/uploads/2019/09/mine5-1.jpg)
6. Click**PLAY** to check.

### 4\. Turn off the Sound in Minecraft

 Sound is not a necessary part if you want to speed up your Minecraft. Although you may feel a little quite, it’s an easy way to make Minecraft run faster.

1. Click**Options** .  
![](https://images.drivereasy.com/wp-content/uploads/2019/09/mine7.jpg)
2. Click**Music & Sounds.**  
![](https://images.drivereasy.com/wp-content/uploads/2019/09/mine12.jpg)
3. Turn it off.

4. Play the game to check.

### 1\. Give Minecraft more RAM

 RAM (Random Access Memory) is an internal memory that exchanges data directly with the CPU. RAM is like a temporary storage area between the CPU and the hard disk. Therefore, giving Minecraft more RAM can increase the speed of the game.  
 Here’s how:

1. Check your installed memory by pressing the**Windows logo key + Pause key** together. You’ll see how much RAM space you have.

### 2\. Set Java as a priority

 This method may not very effective but it’s still worth trying. Java is an important software for Minecraft. So giving it enough room to run smoothly will help speed up Minecraft.

1. Press**Ctrl + Shift + Esc** together to open the Task Manager.
2. Click Details.
3. Right-click on Java, and choose**Set priority > High** .

### 3.**Close unnecessary programs**

 Programs in the background can have an impact on Minecraft performance. Many programs will take valuable resources and slow down the Minecraft running speed. You can open Task Manager to end these unnecessary programs.

1. Press**Ctrl + Shift + Esc** together to open the Task Manager.
2. Choose the program and click**End task** .  
![](https://images.drivereasy.com/wp-content/uploads/2019/09/end-task.jpg)

### 4\. Plug your laptop into a power source (for laptop users)

 GPU and CPU need enough power to fully work. If the laptop battery is in a low state, many laptops will automatically throttle the GPU and CPU and slow down Minecraft. For better game performance, make sure you have a full-filled battery or plug the power plug while playing the game.
