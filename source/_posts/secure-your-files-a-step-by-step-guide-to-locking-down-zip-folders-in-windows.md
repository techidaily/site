### Key Takeaways

* To create a passworded ZIP with 7-Zip, right-click the files you want to protect and navigate to 7-Zip > Add to Archive. Set a password in the "Encryption" section, then click "OK."
* To create a passworded ZIP with WinRAR, right-click the desired files, select "Add to Archive," and then click the "Set Password" button.

 Want to protect your ZIP archives with a password? While Windows doesn't have a built-in option to do that, you can use free apps like 7-Zip and WinRAR to [add password protection](https://screen-activity-recording.techidaily.com/new-screen-recording-mastery-with-lenovo-gear-for-2024/). We'll show you how to use those apps.

 Make sure to note your password somewhere safe, like in a [password manager](https://facebook-video-content.techidaily.com/updated-how-to-create-facebook-video-ads-with-free-video-creation-kit-for-2024/), as you'll need it each time you want to extract files from your password-protected ZIP.

##  Password Protect a ZIP Using 7-Zip

[7-Zip](https://www.7-zip.org/) is a free and open-source app that you can use to create and extract files from various archive formats, including ZIP. With this app, you choose the files to add to an archive, set the password, and let the app secure your archive's contents.

 To start, download and install [7-Zip](https://www.7-zip.org/) on your Windows PC.

 Next, [open a File Explorer window](https://youtube-web.techidaily.com/ed-2024-approved-streamers-financial-health-check-in-youtubers/) and locate the files to add to a ZIP archive. Select all these files, [right-click](https://desktop-recording.techidaily.com/updated-the-art-of-recording-fun-6-techniques-to-document-minecraft-for-2024/) any one file, and choose 7-Zip > Add to Archive.

![Select 7-Zip > Add to Archive.](https://static1.howtogeekimages.com/wordpress/wp-content/uploads/2022/07/1-7-zip-add-to-archive.png) 

 You'll see an "Add to Archive" window. Here, in the "[Encryption](https://facebook-video-share.techidaily.com/the-essential-guide-to-youtube-video-lighting-tips-for-2024/)" section on the right, click the "Enter Password" field and type the [password you want to use](https://extra-hints.techidaily.com/crafting-authenticity-in-client-testimonial-videos-for-2024/). Type the same password in the "Reenter Password" field.

 Then, click the "Encryption Method" drop-down menu and choose "AES-256," a popular cipher [used by banks and the US military](https://review-topics.techidaily.com/in-2024-full-guide-to-fix-itoolab-anygo-not-working-on-meizu-21-pro-drfone-by-drfone-virtual-android/). If you want, adjust any other options as you desire.

 Finally, start making your archive by clicking "OK" at the bottom.

![Configure encryption and click "OK."](https://static1.howtogeekimages.com/wordpress/wp-content/uploads/2022/07/2-7-zip-enter-zip-password.png) 

 7-Zip will create your password-protected ZIP archive in the same folder as your selected files. When you open this archive, you'll be asked to enter the password to [extract files](https://some-guidance.techidaily.com/new-strategies-for-streaming-fb-live-on-zoom-platform/) out of it.

![The password prompt when you open an encrypted ZIP file in 7-Zip.](https://static1.howtogeekimages.com/wordpress/wp-content/uploads/2023/12/open-passworded-zip.png)

##  Encrypt a ZIP Archive Using WinRAR

[WinRAR](http://www.win-rar.com/) is another program very similar to 7-Zip that has been around forever. Unlikely 7-Zip, it isn't technically free, but you can use it indefinitely. This [file compression](https://extra-information.techidaily.com/top-30-camcorders-directly-at-your-eyes/) app allows you to make and extract files from various archive types, including ZIP. You can use the app to secure your archives with a password as well.

 To do that, first, download and install the free version of [WinRAR](https://www.win-rar.com/) on your Windows PC.

 Then, [open a File Explorer window](https://pokemon-go-android.techidaily.com/how-to-get-and-use-pokemon-go-promo-codes-on-realme-c67-4g-drfone-by-drfone-virtual-android/) and find the files to add to your archive. Select all your files, right-click any one file, and choose "Add to Archive."

 If you don't see WinRAR's "Add to Archive" option, give your [Windows 10](https://article-posts.techidaily.com/comparing-the-creme-de-la-creme-gopro-hero5-black-to-hero4-silver-for-2024/) or [Windows 11](https://screen-video-capture.techidaily.com/updated-in-2024-addressing-mute-problems-in-obs-live-recording/) PC a restart.

![Select "Add to Archive."](https://static1.howtogeekimages.com/wordpress/wp-content/uploads/2022/07/4-winrar-add-to-archive.png)

 On the "Archive Name and Parameters" window, click the "Set Password" button.

![Choose "Set Password."](https://static1.howtogeekimages.com/wordpress/wp-content/uploads/2022/07/5-winrar-set-zip-password.png) 

 On the "Enter Password" window, select the "Enter Password" field and type your password. Type the same password in the "Reenter Password for Verification" field.

 Then choose "OK" at the bottom.

![Set the ZIP password and click "OK."](https://static1.howtogeekimages.com/wordpress/wp-content/uploads/2022/07/6-winrar-enter-zip-password.png) 

 In the "Archive Format" section, choose "ZIP" so the app makes a ZIP archive. Then feel free to change any other options if you want.

 Finally, when you're ready to make the archive, click "OK."

![Choose "ZIP" and click "OK."](https://static1.howtogeekimages.com/wordpress/wp-content/uploads/2022/07/7-winrar-make-password-zip.png) 

 WinRAR will make a new ZIP archive that is protected with your chosen password. You can now [share this ZIP](https://facebook-video-files.techidaily.com/updated-from-darkness-to-daylight-funniest-incarcerated-facebook-friends-quotes/) with anyone you want, and they'll have to enter the correct password to extract its files.
